# Qalam

Kids trace the 28 Arabic letters (in all their forms) and English A to Z and a to z with a finger or mouse: free, offline, no ads, no accounts, no tracking.

## Run it

Needs Node 22.18 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5187.

- `npm test` runs the trace-checking tests.
- `npm run build` writes the installable, offline app to `dist/`; `npm run preview` serves it at http://localhost:5188.
